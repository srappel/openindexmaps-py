## Documentation Standard Used Here

These chapters describe:

- behavior that is directly implemented in source files
- behavior that is directly exercised by the current tests
- follow-up items where the README or code suggests an intent but the implementation is incomplete or ambiguous

This means the docs distinguish between:

- current features
- stated project goals
- items that need clarification
